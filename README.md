** Plataforma web para la gestión de citas entre profesionales y clientes**

Este proyecto abordó la problemática de la gestión de citas entre profesionales de distintas áreas y sus clientes, donde la coordinación manual de horarios, la ausencia de confirmaciones oportunas y la falta de un mecanismo integrado de pago generan cruces de agenda, inasistencias y pérdida de tiempo para ambas partes. El objetivo fue analizar, diseñar e implementar una plataforma web denominada Citas Pro, que permite a los clientes registrarse, buscar al profesional de su interés y agendar una cita de acuerdo con la disponibilidad real de este. El sistema oculta automáticamente las franjas horarias que ya se encuentran ocupadas, evitando así la duplicidad de turnos. Al solicitar una cita, el profesional recibe una notificación tanto en la plataforma como en su correo electrónico, desde donde puede aceptarla o rechazarla. Una vez aceptada, el cliente recibe un correo con acceso a la pasarela de pago PayPal y, si realiza el pago dentro de las 24 horas siguientes, la cita queda confirmada y se notifica por correo a ambas partes. Adicionalmente, cada correo incluye la opción de recordatorio, que agenda el evento directamente en Google Calendar, y el profesional puede registrar notas sobre cada cita dentro de la misma plataforma. La solución implementada integra la gestión de agenda, las notificaciones, el pago en línea y el seguimiento de las citas en una sola herramienta, ofreciendo un flujo confiable, automatizado y accesible tanto para profesionales como para clientes.
